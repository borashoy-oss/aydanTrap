📐 Қисықсызықты трапецияның ауданы

Жаңа білімді меңгеру · Интеграл арқылы ауданды есептеу

Анықтама

y = f(x) ≥ 0, x = a, x = b түзулері және Ox осімен (яғни y = 0) шектелген фигура қисықсызықты трапеция деп аталады.
📈 Жоғарғы шекара: y = f(x)
📉 Төменгі шекара: y = 0 (Ox осі)
📏 Сол шекара: x = a
📏 Оң шекара: x = b

Негізгі формула

S = ∫ab f(x) dx = F(b) − F(a)

мұндағы F(x) — f(x) функциясының алғашқы функциясы (антипроизводная), яғни F'(x) = f(x).

Қисықсызықты трапецияның сызбасы

Мысал

📘 Есеп: y = x², 0 ≤ x ≤ 2 қисықсызықты трапециясының ауданын табыңыз.

1-қадам. Шекараларды анықтаймыз: a = 0, b = 2, f(x) = x²
2-қадам. Формуланы қолданамыз: S = ∫02 x² dx
3-қадам. Алғашқы функцияны табамыз: F(x) = x³/3
4-қадам. Ньютон-Лейбниц формуласы: S = F(2) − F(0)
5-қадам. Есептейміз: S = 2³/3 − 0³/3 = 8/3 − 0
✅ Жауабы: S = 8/3 ≈ 2,67
